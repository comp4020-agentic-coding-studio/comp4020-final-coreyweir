The breakthrough that moved the work forward was realising that I didn't need to start from scratch. I spent 4 weeks working on Riff, 
took a break when my VPS provider incorrectly flagged my account, then just never returned to the project once it was no longer going
to be useful for the course.

This work made me want to be the sort of software engineer that actually finishes things. Far too often, I start working on a project,
make a lot of progress, then get distracted working on something else and forget about it. I want to finish things and get them to the
'polished' stage, not just stop once they reach 'functional'.
